# PixelmonBee — Site

Site responsivo da PixelmonBee, feito em HTML/CSS/JavaScript puro.

## Arquivos
- `index.html` — página principal
- `style.css` — visual, animações e responsividade
- `script.js` — menu mobile, copiar IP, filtros da loja e animações
- `assets/bee-mascot.jpg` — imagem fornecida pelo usuário
- `assets/loja-banner.png` — banner fornecido pelo usuário

## Antes de publicar
O botão "Abrir Discord" está como placeholder porque o convite/link do Discord não foi informado. No `index.html`, procure:
`<a class="btn btn-primary discord-btn" href="#" ...>`
e troque `#` pelo seu convite do Discord.

## Publicação gratuita
Este é um site estático e pode ser publicado em serviços de hospedagem estática gratuita, como GitHub Pages ou Cloudflare Pages.
