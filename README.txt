## Publicar no GitHub Pages
1. Crie/abra seu repositório no GitHub.
2. Envie os arquivos da raiz deste ZIP.
3. Mantenha `index.html` na raiz.
4. Vá em Settings → Pages.
5. Em Source, escolha `Deploy from a branch`.
6. Selecione a branch `main` e a pasta `/(root)`.
7. Salve e aguarde o GitHub Pages publicar.

Não é necessário Node.js, banco de dados ou servidor próprio: o site é estático.
