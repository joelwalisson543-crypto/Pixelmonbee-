COMO PUBLICAR NO GITHUB PAGES:
1. Envie os arquivos da raiz para o repositório.
2. Não renomeie index.html, ticket.html, style.css ou script.js.
3. Se preferir usar a pasta assets, ela já está incluída no ZIP, mas o site principal usa as imagens da raiz para facilitar o upload pelo celular.
4. Em Settings > Pages, use Deploy from a branch > main > /(root).
